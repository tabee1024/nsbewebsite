# NSBE Website (CSUN)

Website for the National Society of Black Engineers, CSUN chapter.

Built with React, [Vite](https://vitejs.dev/), and [Tailwind CSS](https://tailwindcss.com/).

## Getting Started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser. The page reloads automatically as you make changes.

## Available Scripts

### `npm run dev`

Runs the app in development mode with hot module reloading.

### `npm run build`

Builds the app for production to the `dist` folder, minified and optimized.

### `npm run preview`

Serves the production build locally, so you can sanity-check it before deploying.

## Tech Stack

- **React 19**
- **Vite** — dev server and build tool
- **Tailwind CSS** — utility-first styling
- **React Router** — client-side routing
